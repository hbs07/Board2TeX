## 一、项目背景与目标

本项目名为 Board2TeX,旨在解决这样一个问题:将一张板书或白板照片,自动整理为一份可直接编译的 LaTeX 文档。

在日常学习中,用手机拍摄板书十分方便,但到了复习阶段,要将照片中的公式逐条录入 LaTeX 或 Word,不仅耗时,也容易出错。目前可用的同类工具(如 Mathpix)存在两点不足:一是按次收费;二是仅支持单条公式的截图识别,无法处理整版板书,也不支持英文与公式的混排。因此,我们计划开发一个免费、且能够处理整版板书的工具。目标用户有两类:希望将板书归档复习的学生,以及需要将课堂推导整理为讲义的助教和教师。与现有工具相比,本项目的创新点在于提供从整版板书到可编译文档的完整端到端流程,支持英文与公式混排,并提供错题本归档功能,这些均是现有工具所不具备的。

---

## 二、系统方案

处理流程分为五个阶段:

```
输入照片
  ↳ ① 图像预处理:缩放 → 灰度 → 光照归一化 → 二值化 → 裁剪
  ↳ ② 版面分析:按行切分版面,并判断每行属于文字或公式
  ↳ ③ 识别:文字行交由 PaddleOCR,公式行交由 pix2tex
  ↳ ④ 合成:按阅读顺序拼接为可编译的 .tex
  ↳ ⑤ 应用:在桌面程序中校对、导出 PDF、存入错题本
```

技术栈为 Python、OpenCV、PaddleOCR、pix2tex、PyQt5 与 SQLite。识别部分采用开源预训练模型,在 CPU 环境下即可运行,不依赖独立显卡。

---

## 三、关键技术问题

我们在项目中重点处理以下四个问题。

第一,光照与二值化增强。手机拍摄的板书通常明暗不均,先用 CLAHE 做光照归一化,再用 Otsu 自动阈值二值化,让字迹与背景清晰分离;两者均为 OpenCV 现成函数的组合使用。

第二,版面切分。板书按行书写,可通过统计每行的前景像素数量,以空白处作为行与行之间的分界。该方法实现简单且稳定。第一版仅处理单列版面。

第三,文字与公式的区分。两类内容需要不同的识别引擎,因此先以宽高比、连通域等几何特征进行初步判断;对于把握不足的结果,允许用户在界面上手动修正。

第四,可编译 LaTeX 的生成。百分号、&、下划线等字符若不转义将导致编译失败,需统一做转义处理,并借助 xelatex 实际编译来验证结果。

此外,为确保按时交付,第一版暂不支持透视矫正、双列版面、行内切块、反光修复与实时预览(拍照时尽量拍正即可),这些功能留待后续版本实现。上述问题中,光照增强、版面切分与混排合成都由本项目自行实现,也是项目工作量的主要来源;识别部分使用开源预训练模型,我们的工作在于封装、调用与后处理。

## 四、团队分工

本项目采用"共同参与、模块主责、交叉互补"的分工方式。需求分析、方案设计与进度安排由四名成员共同讨论确定;开发阶段每人主责一个核心模块,同时两两结对交叉参与另一个模块的开发与代码评审,保证四人对完整流程都有整体理解。

模块主责如下:组长胡秉善主责图像预处理入口、主程序集成、界面框架与 PDF 编译;郭佳欣主责图像增强与按行切分;陶谱州主责识别引擎的调用与 LaTeX 拼接;李若宸主责界面、导出与错题本。

为保证协作顺畅,Week 6 冻结接口后,每人基于统一的函数骨架、测试图片与验证命令,先跑通自己模块的最小示例;联调阶段全员参与问题定位与修复。代码统一提交至 GitHub,以 commit 记录作为各成员参与的依据。本次期中汇报同样由四名成员接力完成,每人讲解与自己工作对应的部分。
