# Board2TeX 环境安装指南(全组统一)

> 适用:B/C/D 三位组员在**自己的电脑**上从零装环境。
> 花费时间:约 20~40 分钟(取决于网速,依赖约 2~3GB)。
> 成品标准:最后一步 `check_env.py` 输出 **15 OK / 0 FAIL**。
> 维护:胡秉善(A)。安装步骤在 A 的机器上全部验证通过。

---

## 0. 开始前的检查

| 检查项 | 怎么查 | 不满足怎么办 |
|---|---|---|
| Windows 10/11 | — | — |
| 磁盘剩余 ≥ 5GB | 资源管理器看 C 盘和装代码的盘 | 清理后再来 |
| 能访问 GitHub | 浏览器打开 `github.com` | 用手机热点试试 |

**路径要求:代码必须放在纯英文路径下**(如 `D:\Board2TeX`)。中文路径会让 OpenCV/Paddle 报莫名错误,这是本项目头号大坑。

---

## 1. 安装 uv 和 Git(已装过的跳过)

1. **Git**:下载 https://git-scm.com/download/win ,一路默认 Next;装完**重开** PowerShell,敲 `git --version` 能出版本号即可;
2. **uv**:PowerShell 里执行
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
   装完**重开** PowerShell,敲 `uv --version` 能出版本号即可。

> 每次敲完命令没反应/报"不是内部或外部命令",先关掉 PowerShell 重开再试一次。

---

## 2. 拿代码 + 建环境(一次性)

**打开 PowerShell,逐条执行**(假设装在 D 盘):

```powershell
# 换到 D 盘根目录
D:

# 拿代码(第一次执行会要求登录 GitHub,按提示用浏览器授权)
git clone https://github.com/hbs07/Board2TeX.git
cd Board2TeX

# 建 Python 3.12 虚拟环境(和组长机器版本一致)
uv venv .venv_b2t --python 3.12

# 装全部依赖(约 2~3GB,包含 paddle/pix2tex/torch,耐心等)
uv pip install --python .venv_b2t\Scripts\python.exe -r requirements.txt
```

---

## 3. 每次写代码前的固定动作

```powershell
cd D:\Board2TeX
.venv_b2t\Scripts\Activate.ps1
```

激活成功的标志:命令行最前面多了 `(.venv_b2t)`。

**三条铁律:**
1. **没激活环境,不要跑任何 python 命令**——会用到系统 Python 3.14,那里面什么都没装;
2. **装任何新包都用 `uv pip install 包名`**(激活状态下),不要用 `pip install`;
3. 以后组里统一用 Python 3.12 + 这套虚拟环境,不要自己另装 Python 包。

> 如果激活时报"禁止运行脚本"(执行策略问题),执行下面这条再激活:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

---

## 4. 验证安装(必做)

激活环境后:

```powershell
python tools/check_env.py
```

期望输出:**15 OK / 0 FAIL**。

注意其中两项会额外下载模型(慢,属正常):
- PaddleOCR 中文识别
- pix2tex 公式识别

之后可以顺手跑组长的冒烟测试:

```powershell
python tools/smoke_test.py
```

**全过 = 环境完成,截图发群。**

## 5. 常见问题对照表

| 症状 | 原因 | 解法 |
|---|---|---|
| `uv` / `git` 不是内部或外部命令 | 没重开终端,或没装上 | 重开 PowerShell;还不行就重装 |
| 激活后命令行没有 `(.venv_b2t)` 前缀 | 执行策略拦了脚本 | 见第 3 节的 `Set-ExecutionPolicy` |
| `python` 后报 `No module named cv2` | 忘了激活环境 | 先激活,再跑命令 |
| `check_env.py` 卡在下载模型很久 | 模型文件大 | 等着;超过 20 分钟截图发群 |
| 读图片报错或路径相关报错 | 路径里有中文 | 代码和图片全放英文路径 |
| `pip install` 装了包但还是 import 失败 | 装到了系统 Python | 删掉重装:`uv pip install --python .venv_b2t\Scripts\python.exe -r requirements.txt` |
| 磁盘不够 / 装到一半失败 | C 盘缓存满 | 清理 C 盘后重跑第 2 节最后一条 |

**通用规则:卡住超过半小时,截图(连同你敲的命令)发群里,别闷头重装。**
